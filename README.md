# Smart Swarm Logistics
A multi-agent system for dynamic warehouse task allocation using Model-Context Protocols (MCP) and TinyML.

## Features
- Multi-agent coordination via MCP (MQTT/WebSockets).
- Lightweight AI models for agent decision-making.
- Simulated warehouse environment with tasks and obstacles.
- Visualization of agent behaviors.

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/venysssssssssss/smart-swarm-logistics.git
   cd smart-swarm-logistics
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the simulation:
   ```bash
   python scripts/run_simulation.py
   ```
